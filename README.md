# Tienda de Shopify

Repositorio de la tienda Shopify.

## Skill incluida

`.claude/skills/tienda-shopify-v2/` contiene la skill **Tienda Shopify v2**, que
Claude Code carga automáticamente al trabajar en este repositorio. Sirve para
crear y editar la tienda (tema, landing, página de producto, páginas legales,
header y footer) y publicar los cambios.

Para empezar, abre Claude Code en este repositorio y escribe, por ejemplo:
"Quiero montar mi tienda de Shopify".
